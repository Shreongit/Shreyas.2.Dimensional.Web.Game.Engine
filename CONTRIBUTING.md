# Contributions and Permission Requests

## Proprietary project

S2DWGE is proprietary software. This repository is public for educational viewing and technical study only. Public visibility does not grant permission to copy, modify, redistribute, or incorporate the code into another project.

## Before submitting a contribution

Do not submit copied code, patches, or other material that you do not have the right to contribute. Do not submit changes that reproduce or redistribute S2DWGE source code outside this repository.

Any proposed contribution that requires copying, modifying, or redistributing proprietary project code requires **prior written permission** from the rights holder. Opening a pull request does not itself grant permission.

## Reporting bugs and suggesting improvements

You may use the repository's issue tracker to describe a bug or suggest an improvement in your own words. Avoid including copied portions of proprietary source code in public issues or external projects.

When reporting a problem, include:
- A clear description of the behavior.
- Steps to reproduce it, where possible.
- Browser, operating system, and runtime versions when relevant.
- Expected behavior and actual behavior.

## Permission requests

For written permission to copy, modify, redistribute, or incorporate code into another project, contact the repository owner through the contact method listed on the project's GitHub profile. Wait for explicit written permission before proceeding.
